# Quickstart

Playwriter Session Cloud is a hosted remote MCP for AI agent browser MCP session.

## Fast Path

1. Open Playwriter Session Cloud and select the buyer plan.
2. Create or request a bearer token from the hosted product.
3. Add https://playwritermcp.clauxel.com/mcp to a compatible MCP client.
4. Run tools/list, then call session_open with public-safe sample data.
5. Save the returned receipt or export for human review.
